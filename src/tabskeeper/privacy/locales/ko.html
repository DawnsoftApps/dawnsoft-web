Tabs Keeper 개인정보 처리방침

업데이트: 2026년 9월 11일

요약

Tabs Keeper(이하 ‘앱’)는 대부분의 데이터를 사용자의 기기에서 처리합니다. 개발자는 탭 콘텐츠를 수집하는 서버를 운영하지 않으며, 앱에 제3자 광고, 행동 분석 또는 앱 간 추적 SDK를 포함하지 않고, 사용자의 데이터를 판매하지 않습니다.

사용자가 iCloud를 켜거나, 구매하거나, 웹사이트 아이콘을 불러오거나, 시스템 공유 기능을 사용하거나, 피드백을 보낼 때만 관련 데이터가 Apple 서비스, 해당 웹사이트 또는 사용자가 선택한 수신자에 의해 처리됩니다.

1. 적용 범위

이 방침은 iOS 및 macOS용 Tabs Keeper 앱과 Safari 웹 확장 프로그램에 적용됩니다. 각 구성 요소가 어떤 데이터를 처리하는지, 처리 목적은 무엇인지, 데이터가 어디에 저장되는지, 사용자가 데이터를 어떻게 관리할 수 있는지를 설명합니다.

2. 앱이 처리하는 데이터

데이터 유형내용 및 목적
탭 데이터탭 제목, 전체 URL, 웹사이트 도메인, 내부 식별자 및 정렬 순서를 탭 저장, 표시, 검색, 공유 및 다시 열기에 사용합니다. URL 자체에 사용자가 방문한 콘텐츠에 관한 정보가 포함될 수 있습니다.
정리 데이터아카이브 및 컬렉션 이름, 탭 소속, 생성 및 수정 시간, 휴지통 상태를 콘텐츠 정리와 동기화에 사용합니다.
기기 내 설정화면 모드, 기능 소개 표시 여부, iCloud 켜기·끄기 등의 설정을 사용자의 선택을 기억하는 데 사용합니다.
구매 상태App Store 제품 식별자, 유효한 이용 권한, 구독 만료일 및 자동 갱신 상태를 Pro 기능 표시와 활성화에 사용합니다.
사용자가 제공하는 피드백이메일로 피드백을 보낼 때 사용자가 본문, 첨부 파일 및 연락처 정보를 직접 선택합니다. 앱은 전송 전에 이러한 내용을 자동으로 업로드하지 않습니다.

3. Safari 확장 프로그램의 탭 접근

현재 창의 탭을 저장하려면 확장 프로그램에 Safari 탭 및 웹사이트 접근 권한이 필요합니다. 확장 프로그램을 열면 현재 Safari 창에서 저장할 수 있는 탭의 제목, URL 및 사용 가능한 웹사이트 아이콘 주소를 읽어 선택 목록을 표시합니다. 사용자가 저장을 확인한 데이터만 앱의 데이터베이스에 기록됩니다.

확장 프로그램은 웹페이지 본문, 양식 입력값, 비밀번호 또는 쿠키를 읽지 않으며, 사용자의 방문 기록을 지속적으로 기록하거나 생성하지 않습니다. Safari 확장 프로그램 설정에서 언제든지 권한을 확인, 변경 또는 철회할 수 있습니다. 권한을 철회하면 해당 권한이 필요한 저장 기능을 사용하지 못할 수 있습니다.

4. 로컬 저장소 및 앱 그룹

데이터는 기본적으로 기기의 App Group 공유 컨테이너에 로컬 파일로 저장되므로 앱과 Safari 확장 프로그램이 동일한 데이터베이스에 접근할 수 있습니다. 화면 모드, 기능 소개 표시 상태, iCloud 켜기·끄기 등의 설정은 기기에 저장됩니다.

개발자는 이 로컬 데이터베이스를 자체 운영 서버에 자동으로 업로드하지 않습니다. 기기 백업, 시스템 이전 및 운영 체제 차원의 데이터 처리는 사용자의 시스템 설정과 Apple 서비스에 따릅니다.

5. 선택 사항인 iCloud 동기화

iCloud 동기화는 기본적으로 꺼져 있습니다. 사용자가 켜면 앱은 아카이브, 컬렉션, 탭 및 필요한 동기화 메타데이터를 로컬 데이터와 병합하여 Apple ID와 연결된 비공개 CloudKit 데이터베이스에 저장합니다. 이를 통해 같은 Apple ID를 사용하는 기기 간에 동기화할 수 있습니다.

iCloud 동기화를 꺼도 로컬 데이터나 이전에 CloudKit에 저장된 데이터는 자동으로 삭제되지 않습니다. CloudKit은 Apple이 제공하며, 데이터 처리는 Apple 개인정보 처리방침과 사용자의 iCloud 설정을 따릅니다.

6. AI 스마트 선택

Apple Intelligence를 지원하는 기기에서는 사용자가 ‘AI 스마트 선택’을 누른 경우에만 앱이 Apple의 온디바이스 언어 모델을 사용하여 컬렉션 이름과 후보 탭의 제목, 도메인 및 내부 식별자를 분석합니다. 현재 구현은 웹페이지 본문 전체를 입력하지 않으며, 이러한 정보를 개발자 서버로 전송하지도 않습니다.

AI 결과는 선택 제안일 뿐입니다. 탭을 자동으로 저장하거나 삭제하지 않으며, 이미 선택한 탭의 선택을 해제하지도 않습니다. 사용자가 가져오기 버튼을 눌러 확인해야 합니다.

7. 웹사이트 아이콘 요청

파비콘을 표시하기 위해 앱이나 Safari는 탭에서 제공한 아이콘 주소를 사용하거나 해당 웹사이트에 /favicon.ico를 요청할 수 있습니다. 요청은 해당 웹사이트로 직접 전송되며, 일반적인 네트워크 요청과 마찬가지로 IP 주소, 기기 네트워크 정보, User-Agent 등이 전달될 수 있습니다. 앱은 이러한 요청을 개발자 서버로 전달하지 않습니다. 아이콘을 불러오지 못하면 로컬 대체 이미지가 표시됩니다.

8. Pro 구매 및 구독

구매, 구독, 구매 복원 및 구독 관리는 Apple이 App Store와 StoreKit을 통해 처리합니다. 앱은 Apple이 확인한 제품 및 이용 권한 상태를 읽어 Pro 활성화 여부를 판단하고 만료일과 갱신 상태를 표시합니다. 개발자는 사용자의 카드 번호, 전체 결제 정보 또는 Apple ID 비밀번호를 받지 않습니다.

9. 공유 및 이메일 피드백

사용자가 공유 기능을 사용할 때만 앱이 선택한 이름, 탭 제목 및 URL을 시스템 공유 시트에 전달합니다. 이후 해당 데이터는 사용자가 선택한 앱, 서비스 또는 연락처에 의해 처리됩니다. 이메일 피드백을 선택하면 시스템 메일 화면이 열리며, 사용자가 전송 여부와 메일 내용을 확인합니다.

10. 데이터 보관 및 삭제

  • 아카이브, 컬렉션 및 탭은 사용자가 삭제할 때까지 보관됩니다.
  • 휴지통으로 이동된 아카이브와 컬렉션은 7일 동안 보관된 뒤, 다음에 앱을 열 때 영구 삭제됩니다. 그 전에 복원하거나 영구 삭제할 수도 있습니다.
  • 탭이 더 이상 어떤 아카이브나 컬렉션에도 속하지 않으면 해당 기록이 삭제됩니다.
  • 영구적으로 삭제한 콘텐츠가 여러 기기의 데이터를 병합할 때 다시 나타나지 않도록 앱은 항목의 내부 식별자와 삭제 시간만 포함하는 최소한의 삭제 표시를 보관할 수 있습니다. 이 표시에는 탭 제목, URL, 아카이브 이름 또는 컬렉션 이름이 포함되지 않습니다.
  • iCloud를 사용하면 로컬 삭제 내역이 이후 동기화 과정에서 CloudKit에 반영됩니다. 앱을 삭제하는 것만으로는 이전에 iCloud에 저장한 데이터가 삭제되지 않을 수 있습니다.

11. 데이터 공유 및 제3자 서비스

개발자는 사용자의 데이터를 판매하거나 임대하지 않으며 맞춤형 광고에 사용하지 않습니다. 앱에는 제3자 광고 또는 분석 SDK가 포함되어 있지 않습니다. 사용자가 선택한 기능을 제공하기 위해 데이터가 다음 주체에 의해 처리될 수 있습니다.

  • Apple: iCloud/CloudKit, App Store/StoreKit, 시스템 공유, 메일 및 운영 체제 기능을 제공합니다.
  • 해당 웹사이트: 웹사이트 아이콘을 불러올 때만 일반적인 네트워크 요청을 받습니다.
  • 사용자가 선택한 수신자: 시스템 공유 또는 이메일 전송 시 사용자가 확인한 내용만 받습니다.

12. 보안

앱은 앱 샌드박스, App Group, 시스템 권한, StoreKit 검증 및 비공개 CloudKit 데이터베이스 등 Apple이 제공하는 플랫폼 기능을 사용하여 데이터를 보호합니다. 어떤 저장 또는 전송 방식도 절대적인 보안을 보장할 수 없으므로 기기 암호와 Apple ID를 안전하게 관리하세요.

13. 아동의 개인정보 보호

앱은 계정 생성을 요구하지 않으며 사용자의 연령 정보를 적극적으로 수집하지 않습니다. 개발자는 앱을 통해 아동의 개인정보를 알면서 수집하지 않습니다. 이러한 일이 발생했다고 생각되면 아래 방법으로 개발자에게 문의하세요.

14. 귀하의 선택과 권리

Safari 확장 프로그램 권한을 취소하거나 iCloud를 끄고, 탭을 삭제하거나 아카이브와 컬렉션을 휴지통으로 이동해 영구 삭제할 수 있으며, 시스템 설정에서 구매 및 구독을 관리할 수 있습니다. 관련 법률에 따라 열람, 정정, 삭제 또는 처리 제한 등의 권리가 인정되는 경우 아래 방법으로 문의해 주세요.

15. 방침 변경

기능, 데이터 처리 방식 또는 적용되는 요구 사항이 중요하게 변경되면 개발자는 이 방침과 위의 업데이트 날짜를 수정합니다. 필요한 경우 앱의 업데이트 설명을 통해서도 안내합니다.

16. 문의

이 방침 또는 데이터 처리에 관한 질문은 앱의 ‘설정’ → ‘이메일 피드백’에서 개발자에게 문의하세요. 피드백에 비밀번호, 결제 정보 또는 그 밖의 불필요한 민감 정보를 포함하지 마세요.
